$ GENERAL EXECUTIVE DECISIONS
$ E1. Suchard's transcription -> IPA/DiaSim symbols (his Table 1.1, p. 4):
$       ˀ = ʔ ; h = h ; ḥ = ħ ; ˁ = ʕ ; ḫ = x ; ġ = ɣ ; ś = ɬ ; š = ʃ ; y = j ; g = ɡ ; r = r ;
$       ṭ = tʼ ; q = kʼ ; ˢs = t͡s ; ᵈz = d͡z ; ᵗṣ (later written ṣ) = t͡sʼ ; θ̣ = t͡θʼ ; ṣ́ = t͡ɬʼ ;
$       ε = ɛ ; ə = ə ; ā̊ = ɔː ; macron = ː ; acute accent = primary stress (ˈ, [+prim]).
$       Spirants of 5.7: ḇ = v, ḡ = ɣ, ḏ = ð, ḵ = x, p̄ = f, ṯ = θ.
$ E2. Ejectives ("emphatics") are [+cg] consonants. As the emphatics are not in DiaSim's
$     symbolDefs.csv, symbolDefs-hebrew.csv adds: tʼ (t +cg), kʼ (k +cg), t͡sʼ (t͡s +cg),
$     t͡θʼ (θ with -cont,+delrel,+cg), t͡ɬʼ (ɬ with -cont,+delrel,+cg). Everything else is unchanged gamma.
$ E3. Geminates (and Suchard's "long" consonants) = two identical segments (b b), not Cː.
$ E4. DiaSim has no syllables. "Open syllable" = the vowel is followed by #, by another vowel, or by one
$     non-syllabic + a vowel; "closed" = followed by [-syl] + {[-syl] or #}. Glides j, w count as
$     consonants, as in Suchard ("29 consonantal phonemes" incl. w, y). Suchard's $ (syllable boundary)
$     is rendered with these contexts.
$ E5. Stress is assigned by 2.5; the input lexicon is assumed unstressed (Suchard: PNWS stress cannot be
$     reconstructed). Plain vowel symbols (a, e, o, aː ...) are the UNSTRESSED ones, so symbol rules on
$     them only hit unstressed vowels. Secondary stress is not used.
$ E6. "Prosodic word" = DiaSim word. Proclitics (Suchard joins them with a hyphen) must be joined to
$     their host in the lexicon. Pausal (utterance-final) forms cannot be distinguished; 4.2 is comment-only.
$ E7. DiaSim has no negation. Negative conditions are written as follows:
$     (a) "two DIFFERENT consonants" / "not a geminate": one line per distinguishing feature, using a
$         negative alpha (C1 [αF] vs C2 [-αF]), or, where that would multiply lines, a revert line using
$         identity alphas (one distinct variable per feature);
$     (b) "except after w and o" (2.8): a temporary protect symbol, ɑː, which occurs nowhere else
$         and is restored at once.
$ E8. Gutturals = ʔ h ħ ʕ plus the velar fricatives x ɣ (Suchard's definition, p. 10 fn. 4) until they
$     merge (5.6). For "not after/adjacent to a guttural", non-guttural consonants =
$     {[+ant];[+cor];[+cons,-cont];[+nas];j;w}.
